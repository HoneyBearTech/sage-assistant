Sage

Welcome to Sage. A few steps get it ready; you can change everything later in Settings.

Where should Sage think?

On this computer, nothing you type leaves the PC. An online service is set up in Settings.

The local model runner

Sage thinks on this computer through a separate program, the local model runner.

  1. Open the install guide and follow its steps to install the local model runner.
  2. Start the runner.
  3. Come back here and choose Check again.

Choose a model

The model is what Sage thinks with. The local model runner downloads it once. Choosing a model here makes Sage think on this computer, even if it uses an online service now.
